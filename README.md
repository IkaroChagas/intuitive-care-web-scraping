# Python Intuitive Care Web Scraping

[English](#english) | [Português](#português)

## English

### Overview

This repository contains a web scraping test script that demonstrates how to collect data from a web page using web scraping techniques.

### Technologies Used

- **Python 3.x**
- **zipfile**
- **pandas**
- **requests** and **BeautifulSoup** for web scraping
- **pip** for dependency management
- (Optional) **Virtual Environment** for dependency isolation

### Prerequisites

- Python ≥ 3.10.x installed
- Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```
- (Optional) Virtual environment (`venv` or `virtualenv`)

### Installation & Running

1. **Clone the repository**  
   ```bash
   git clone <your-repo-URL>
   cd <repo-folder>
   ```
2. **Run the script**  
   ```bash
   python main.py
   ```
